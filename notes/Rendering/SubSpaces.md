Portals networks can have any number of portals bound to them
If the portals teleport directly to eachother, this doesn't really make sense, so to compensate for that, subspaces need to be supported

These also have the benefit of the fact that the subspaces are stripped down environments, so rendering logic can be extremely minimal for these by default
Obviously, in the [[API]], devs will be able to do more with it than the base mod will
